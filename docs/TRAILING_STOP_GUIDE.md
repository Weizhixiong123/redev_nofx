# NOFX 移动止损使用指南

## 概述

移动止损（Trailing Stop）是一种动态的风险管理机制，它会根据价格变化自动调整止损位置，目标是在保护利润的同时给交易留出足够的波动空间。

本功能参考了 Freqtrade 的移动止损实现，并针对 NOFX 的 AI 交易特性进行了优化。

## 核心特性

### 1. 动态止损调整
- 价格上涨时，止损价格自动跟随上移
- 价格下跌时，止损价格保持不变（只能向有利方向移动）
- 保护已实现的利润，同时给予足够的波动空间

### 2. 正向止损切换
- 初期使用基础止损（如 -3%）
- 盈利达到设定阈值后，切换到更紧密的正向止损（如 -2%）
- 平衡风险保护和利润最大化

### 3. 灵活配置
- 支持多种配置模式
- 可根据市场特性和交易风格调整参数
- 与现有风控机制无缝集成

## 配置参数

### 基础配置

```json
{
  "risk_control": {
    "enable_trailing_stop": true,              // 启用移动止损
    "max_stop_loss_pct": 3.0,                  // 基础止损 3%
    "trailing_stop_positive": 0.02,            // 正向止损 2%
    "trailing_stop_positive_offset": 0.03,     // 偏移 3% 后触发
    "trailing_only_offset_is_reached": false   // 立即开始移动
  }
}
```

### 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `enable_trailing_stop` | bool | false | 是否启用移动止损功能 |
| `max_stop_loss_pct` | float | 3.0 | 基础止损百分比（3% = -3%） |
| `trailing_stop_positive` | float | 0.02 | 正向止损百分比（2% = -2%） |
| `trailing_stop_positive_offset` | float | 0.03 | 正向止损触发偏移（3%） |
| `trailing_only_offset_is_reached` | bool | false | 是否仅在偏移达到后才移动 |

## 工作原理

### 阶段 1：初始化（开仓时）

```
开仓价格: 100 USDT
基础止损: 3%
初始止损价格: 100 × (1 - 0.03) = 97 USDT
```

### 阶段 2：价格上涨（未达偏移）

**盈利 < 3%：使用基础止损 3%**

```
价格: 101 USDT
盈利: 1%
止损: 101 × (1 - 0.03) = 97.97 USDT ✅ 上移
```

```
价格: 102 USDT
盈利: 2%
止损: 102 × (1 - 0.03) = 98.94 USDT ✅ 上移
```

### 阶段 3：达到偏移（切换正向止损）

**盈利 ≥ 3%：切换到正向止损 2%**

```
价格: 103.5 USDT
盈利: 3.5% ≥ 3% ✅ 触发切换
止损: 103.5 × (1 - 0.02) = 101.43 USDT ✅ 大幅上移
```

### 阶段 4：持续跟踪

```
价格: 105 USDT
盈利: 5%
止损: 105 × (1 - 0.02) = 102.9 USDT ✅ 继续上移
```

```
价格: 106 USDT
盈利: 6%
止损: 106 × (1 - 0.02) = 103.88 USDT ✅ 继续上移
```

### 阶段 5：价格回调

```
价格: 104 USDT
盈利: 4%
新止损: 104 × (1 - 0.02) = 101.92 USDT
当前止损: 103.88 USDT
结果: ❌ 不移动（101.92 < 103.88）
```

**关键原则：止损只能向有利方向移动！**

### 阶段 6：触发止损

```
价格: 103.5 USDT
当前止损: 103.88 USDT
触发: 103.5 < 103.88 ✅
动作: 市价平仓
类型: TRAILING_STOP_LOSS
```

## 配置模式

### 模式 1：基础移动止损（保守）

```json
{
  "enable_trailing_stop": true,
  "max_stop_loss_pct": 3.0,
  "trailing_stop_positive": 0.0,
  "trailing_stop_positive_offset": 0.0,
  "trailing_only_offset_is_reached": false
}
```

**特点：**
- 始终使用 3% 止损
- 价格上涨时止损跟随
- 简单直观，适合新手

**适用场景：**
- 震荡市场
- 不确定趋势方向
- 初次使用移动止损

### 模式 2：正向移动止损（平衡）

```json
{
  "enable_trailing_stop": true,
  "max_stop_loss_pct": 3.0,
  "trailing_stop_positive": 0.02,
  "trailing_stop_positive_offset": 0.03,
  "trailing_only_offset_is_reached": false
}
```

**特点：**
- 盈利 3% 后切换到 2% 止损
- 平衡波动空间和利润保护
- 最常用的配置

**适用场景：**
- 趋势市场
- 中等波动币种
- 日常交易

### 模式 3：仅偏移后移动（激进）

```json
{
  "enable_trailing_stop": true,
  "max_stop_loss_pct": 3.0,
  "trailing_stop_positive": 0.02,
  "trailing_stop_positive_offset": 0.05,
  "trailing_only_offset_is_reached": true
}
```

**特点：**
- 盈利 5% 前止损固定不动
- 给足初期波动空间
- 盈利后紧密保护

**适用场景：**
- 高波动币种
- 需要大波动空间
- 追求大利润

### 模式 4：紧密跟踪（短线）

```json
{
  "enable_trailing_stop": true,
  "max_stop_loss_pct": 2.0,
  "trailing_stop_positive": 0.01,
  "trailing_stop_positive_offset": 0.02,
  "trailing_only_offset_is_reached": false
}
```

**特点：**
- 止损距离更近
- 快速锁定利润
- 可能过早退出

**适用场景：**
- 短线交易
- 低波动币种
- 快进快出策略

## 与其他风控机制的关系

### 1. 与固定止损的关系

```
移动止损启用时：
- 优先使用移动止损
- 固定止损作为保底

移动止损禁用时：
- 使用固定止损（max_stop_loss_pct）
```

### 2. 与 AI 决策的关系

```
AI 可以建议止损价格，但：
- 移动止损会自动调整
- 代码强制执行移动止损规则
- AI 无法阻止移动止损触发
```

### 3. 与盈利池的关系

```
移动止损和盈利池独立运作：
- 盈利池控制开仓次数
- 移动止损控制平仓时机
- 两者互补，共同保护账户
```

## 注意事项

### 1. 杠杆影响

```
10 倍杠杆下：
- 价格变动 1% = 账户变动 10%
- 移动止损基于价格变动，不是账户变动
- 需要考虑杠杆放大效应
```

### 2. 交易所同步

```
当前实现：
- 本地计算移动止损
- 触发时市价平仓

未来优化：
- 同步到交易所止损单
- 减少网络延迟风险
```

### 3. 回测 vs 实盘

```
回测：
- 使用 K 线高低点
- 可能更准确触发

实盘：
- 使用实时价格
- 可能有延迟
```

### 4. 费用考虑

```
移动止损可能增加交易频率：
- 更频繁触发止损
- 手续费成本增加
- 需要平衡保护和成本
```

## 最佳实践

### 1. 根据市场调整

```
趋势市场：
- 使用较宽的止损
- 给予足够波动空间
- 追求大利润

震荡市场：
- 使用较紧的止损
- 快速锁定利润
- 避免回吐
```

### 2. 根据币种调整

```
BTC/ETH：
- 波动相对较小
- 可以用较紧止损
- 建议 2-3%

山寨币：
- 波动较大
- 需要较宽止损
- 建议 5-8%
```

### 3. 根据持仓时间调整

```
短线（< 1 天）：
- 紧密止损
- 快速止盈
- 1-2% 止损

中线（1-7 天）：
- 平衡止损
- 适度保护
- 2-3% 止损

长线（> 7 天）：
- 宽松止损
- 给予空间
- 5-8% 止损
```


### 常见问题排查

**问题 1：止损没有移动**
```
检查：
1. enable_trailing_stop 是否为 true
2. trailing_only_offset_is_reached 是否为 true 且盈利未达偏移
3. 价格是否真的在上涨
```

**问题 2：止损移动太快**
```
调整：
1. 增大 trailing_stop_positive（如 0.02 → 0.03）
2. 增大 trailing_stop_positive_offset（如 0.03 → 0.05）
3. 启用 trailing_only_offset_is_reached
```

**问题 3：止损移动太慢**
```
调整：
1. 减小 trailing_stop_positive（如 0.03 → 0.02）
2. 减小 trailing_stop_positive_offset（如 0.05 → 0.03）
3. 禁用 trailing_only_offset_is_reached
```

## 总结

移动止损是一个强大的风险管理工具，它通过动态调整止损位置来平衡风险和收益。关键是要：

1. **理解原理**：止损只能向有利方向移动
2. **选择模式**：根据市场和币种选择合适的配置
3. **持续优化**：根据实际效果调整参数
4. **监控日志**：及时发现和解决问题

正确使用移动止损，可以显著提高交易的风险收益比，保护已实现的利润，同时给予足够的波动空间让利润奔跑。
